# Cybersecurity: 13-Day College Program

Welcome to the repository for the **13-Day College Program on Cybersecurity**. This repository is structured to track topics, exercises, lab work, notes, and projects covered throughout the 13-day curriculum.

---

## 📁 Repository Structure

```text
cybersecurity/
├── Day-01/
├── Day-02/
├── Day-03/
├── Day-04/
├── Day-05/
├── Day-06/
├── Day-07/
├── Day-08/
├── Day-09/
├── Day-10/
├── Day-11/
├── Day-12/
└── Day-13/
```

Each day's folder is organized to contain:
- Lecture notes and presentations
- Practical lab guides and walkthroughs
- Code scripts, tools, and configurations
- Assignments and challenge write-ups

---

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/vikas-rathod-16/cybersecurity.git
   cd cybersecurity
   ```

2. **Navigate to the daily modules**:
   ```bash
   cd Day-01
   ```

- Incident Response, Threat Hunting & Digital Forensics
